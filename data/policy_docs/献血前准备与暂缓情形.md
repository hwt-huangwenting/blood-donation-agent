# 献血前准备与暂缓情形

## 一、献血前注意事项

1. 睡眠充足：献血前一天应保证充足睡眠，避免熬夜、疲劳状态献血。
2. 不要空腹：献血前应进食清淡饮食，避免空腹，也避免大量摄入油腻高脂食物（以免血液出现乳糜而影响检测）。
3. 用药注意：献血前几日内如服用药物，应如实告知血站医护人员，由其判断是否可以献血，切勿自行隐瞒。
4. 适当饮水：献血前可适量补充水分，放松心情，避免紧张。
5. 证件准备：献血时请携带本人有效身份证件（身份证、社保卡等）。

## 二、常见暂缓献血情形

依据《献血者健康检查要求》（GB 18467）的通用原则，以下情形一般应**暂缓献血**，
具体间隔时长以当地血站规定为准：

1. **急性疾病未愈**：感冒、发热、急性胃肠炎、急性呼吸道感染等未痊愈，
   或痊愈后未满规定间隔时间。
2. **拔牙或小手术**：拔牙、其他小手术后未满规定间隔（一般建议半个月内暂缓献血）。
3. **疫苗接种**：接种疫苗后未满规定间隔。灭活疫苗一般间隔较短或不受影响，
   减毒活疫苗一般建议间隔约四周，具体以疫苗种类和血站告知为准。
4. **女性生理期**：月经期及前后三天、妊娠期、流产后未满六个月、
   分娩及哺乳期未满一年，均应暂缓献血。
5. **血液暴露类行为**：近期接受输血、较大手术，或进行纹身、纹眉、穿耳洞等
   皮肤穿刺行为后未满规定间隔（一般建议一年内暂缓）。
6. **其他健康异常**：血压异常、重要脏器疾病、贫血等，以血站健康征询与体检结论为准。

## 三、关于「能不能献血」的正确理解

能否献血最终由血站的**健康检查**（健康征询 + 体格检查 + 血液检测）现场判定，
本系统的任何说明都不能替代血站的现场核查。若您正处于上述暂缓情形，
请按规定推迟献血——这既是对用血者安全的负责，也是对您自身健康的保护。

如对具体间隔或自身情况有疑问，请咨询当地血站或采供血机构工作人员。
